# Segurança / Security

## Português (Brasil)

Relate problemas desta versão ao mantenedor,
[Ricardo Barreto](https://github.com/ricardogomesbarreto), informando versão,
modo de operação, comportamento observado e passos de reprodução em disco virtual.
Remova dados pessoais, seriais e caminhos privados dos logs compartilhados.
Os limites conhecidos e as proteções estão no [README](README.md#portugues-brasil).
Questões do Rufus original mantêm as orientações em
[upstream/rufus/SECURITY.md](upstream/rufus/SECURITY.md).

## English

Report issues in this version to the maintainer,
[Ricardo Barreto](https://github.com/ricardogomesbarreto), with the version,
operation mode, observed behavior and reproduction steps using a virtual disk.
Remove personal data, device serials and private paths from shared logs.
See the [README](README.md#english) for current safeguards and known limits.
Original Rufus reports follow its preserved
[security document](upstream/rufus/SECURITY.md).
