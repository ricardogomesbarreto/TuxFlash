# Lufus application icon

`lufus-usb-c-master.png` is the unmodified 1254 x 1254 RGBA master selected
for Lufus on 27 August 2026. It was created with OpenAI image generation for
this project and depicts a USB-C flash drive with the exact word `LUFUS` on
its body.

The application icons under `../icons/hicolor/` are native-size,
premultiplied-alpha Lanczos downscales of that master. They are not cropped,
recoloured, or derived from the inherited Rufus artwork. The master SHA-256
is:

```
4aebc145915e82f051d3e948eee9a8f7c9422fca986271782b5b91fc6db60e48
```
